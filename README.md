# Student Performance Analysis
An analysis of students' academic performance across five schools, comparing internal and external examination results using average scores in Mathematics and English


### Data Sources

The analysis was conducted using two Excel workbooks:

1. Internal Examination Dataset: An Excel workbook containing five worksheets, each representing a participating school. Student records were organised by class, with examination scores across multiple subjects.

2. External Examination Dataset: An Excel workbook containing five worksheets organised by class level (JS1, JS2, JS3, SS1 and SS2). Each worksheet contained student examination records from the five participating schools, with school identification provided in a separate column.

The analysis focused on Mathematics and English. The different components of each subject were consolidated using average scores to obtain an overall score per student.
